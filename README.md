\# Sprint-5

\# QA Java Project 



\## Стэк:

\* Java 11

\* junit 4.13.2

\* maven 3.8.1

\* jacoco-maven-plugin 0.8.12

\* mockito 5.11.0



Задание: протестировать часть программы и написать юнит тесты



\## Тестовые сценарии

1\. Собрать Maven-проект: подключить Jacoco, Mockito и JUnit.

2\. Класс Lion не должен зависеть от класса Feline. Был использован принцип инъекции зависимостей.

3\. Написаны моки с помощью Mockito. Какие именно понадобятся — определено самостоятельно.

4\. Написаны тесты на классы Feline, Cat и Lion.

5\. Применена параметризация и реализован параметризованный тест.

6\. Произведена оценка покрытие с помощью Jacoco: не менее 100% для классов Feline, Cat и Lion.



\## Запуск тестов

\* Чтобы запустить тесты использовать команду:

```

mvn clean test jacoco:report

```
